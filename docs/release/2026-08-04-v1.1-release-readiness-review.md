## 3. 发布级回归测试

### 3.1 Knowledge enabled四类输入

扩展`tests/integration/test_knowledge_application_end_to_end.py`，使用合成published Seed验证：

- 粘贴文本；
- TXT；
- DOCX；
- 文本型PDF。

四类输入均必须：

- 完成同一真实Workflow；
- 生成Report 1.1；
- 获得available岗位知识；
- 使用经过验证的Citation；
- 保持Match Evidence全部来自Resume；
- 通过ScoringEngine复算。

正式`2026.08.1`不会为了测试而改变draft/pending状态。

### 3.2 评分不变与common hard blocker

新增同一输入在Knowledge disabled和enabled下的对照门禁：

- Job Profile完全一致；
- Match结果完全一致；
- Score Summary完全一致；
- Recommendation完全一致；
- 合成知识中的`common hard blocker=true`只进入知识参考，不触发评分封顶。

### 3.3 集中失败路径

新增`tests/integration/test_knowledge_failure_paths.py`，集中验证：

- 损坏SQLite；
- 未来Schema版本；
- 合法Schema但无published版本；
- Seed包含Prompt Injection文本。

前三类数据库问题必须安全回退并保持基础评分与推荐不变；Prompt Injection必须在Seed导入前被拒绝。

### 3.4 Release Metadata与Git Artifact

- pyproject与package版本均为`1.1.0`；
